# Event Report

### Event Objectives

- Guide on psychological and brain (dopamine) management methods to optimize learning.
- Share in-depth Prompt Engineering techniques and how to communicate effectively with AI.
- Orient the core career mindset for IT students preparing to enter the workforce.
- Introduce the method of applying AI Agents into the practical software development process.

### Speakers List

- **Mr Huynh Hoang Long**
- **Mr Nguyen Thinh**
- **Mr. Khang**
- **Ms. Thao**

### Key Highlights

#### 1. Managing Dopamine to "Hack" the Brain and Become "Addicted" to Learning (Speaker: Huynh Hoang Long)

- **Main content:** A guide on how to make learning as engaging as playing video games or surfing social media by tricking the brain.
- **Mechanism:** The brain releases dopamine (a hormone that stimulates excitement) not when receiving a reward, but when anticipating an upcoming reward.
- **Practical methods:**
  - Create random reward systems after each short study session to stimulate curiosity.
  - Maintain a learning "streak" (marking a calendar) to leverage the human psychology of fearing breaking the streak, similar to how gaming apps or social media retain users.
  - Break down massive amounts of knowledge so the brain doesn't get overwhelmed (tricking the amygdala) and apply the 2-minute rule (do immediately whatever can be done in 2 minutes).

#### 2. The Art of Prompt Engineering (Speaker: Nguyen Thinh)

- **Main content:** Presented in English, this session focused on effective communication with AI (LLMs) to get the best results and avoid AI hallucinations or generic responses.
- **Prompt writing method:** A good prompt requires 7 elements:
  1. Role
  2. Instruction
  3. Context
  4. Input/Output format
  5. Example
  6. Constraint
- **Advanced techniques:** Utilizing deep reasoning techniques of AI such as Chain of Thought or Tree of Thought.
- **Practical demo:** Introduced a personal project built on the AWS platform (combining S3, CloudFront, Cognito, API Gateway, Lambda, Bedrock, and DynamoDB) to create a browser extension that optimizes Prompts directly on the web.

#### 3. Career Mindset Orientation for IT Students (Speaker: Mr. Khang)

- **Main content:** Focused on the career mindset for 3rd and 4th-year students rather than dry technical issues. He affirmed that AI does not replace jobs; it is merely a tool to amplify capabilities, making good people even better.
- **Importance of foundation:** Businesses do not require students to know every framework, but rather need individuals with a very solid foundation and the right problem-solving mindset.
- **Core mindset:**
  - Always ask "Why": Must understand the core value and the reason for choosing a technology instead of just getting it done ("What").
  - Uphold Integrity: Need integrity at work, proactively check edge cases in code even when not requested by managers. Build long-term thinking, bravely face mistakes, and continuously learn from the community.

#### 4. BMX Method Using AI Agents in Software Development (Speaker: Ms. Thao)

- **Main content:** Ms. Thao (Software Developer at VIB) introduced the BMX method to solve the situation where AI generates garbage code or loses context when developers force AI to write an entire project from a single massive prompt.
- **How it works:** This method divides the development process into various roles, corresponding to independent AI Agents (PM, Architect, Scrum Master, Developer, Tester).
- **Implementation process:**
  - Start by brainstorming ideas with AI to output the Product Requirements Document (PRD).
  - Analyze the system architecture, then break the project down into Epics and Stories.
  - Each AI Agent will only handle coding or testing for a specific small part, automatically repeating the debugging process until the project is complete without context confusion.

### Lessons Learned

#### Personal Development

- Know how to master emotions and take advantage of the brain's dopamine release mechanism to maintain motivation, turning learning into an engaging habit.

- Understand the BMX methodology and how to decompose a system into AI Agents to safely and effectively apply AI in the coding process without producing garbage code.
