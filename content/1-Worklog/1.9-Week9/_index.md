### Week 9 Objectives:

- Survey and select a suitable topic for building a real-world project on the AWS platform.
- Research methodologies and specialized tools for drawing cloud system architecture diagrams (AWS Architecture Icons, draw.io, Lucidchart).
- Draft the first version of the project architecture diagram and present it to Admin mentors in the First Cloud Journey group for feedback.
